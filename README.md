# Внедрение ИИ на промышленном предприятии — лендинг

Одностраничный рекламный сайт (landing page) на чистом HTML, CSS и JavaScript.
Без сборки, без зависимостей и внешних CDN: страница работает офлайн, все изображения — локальные SVG.

Бренд-заглушка: **«Тут могла бы быть ваша реклама»** (в шапке сокращённо — «ВАША РЕКЛАМА»).

## Что внутри

- **Hero** — оффер, KPI-подсказки, анимированный canvas-фон «нейросеть».
- **Проблема → решение** — четыре типовые точки потерь на производстве.
- **Направления внедрения** — предиктивная диагностика, компьютерное зрение, энергоэффективность, цифровой двойник, ИИ-ассистент.
- **Эффект в цифрах** — счётчики с анимацией и индикаторами.
- **Этапы внедрения** — таймлайн из пяти шагов.
- **ROI-калькулятор** — ползунки (парк, часы простоя, стоимость часа) и живой расчёт экономии и окупаемости.
- **Кейсы** — слайдер с поддержкой клавиатуры и свайпов.
- **FAQ** — аккордеон с корректными `aria-expanded` / `role="region"`.
- **Форма заявки** — валидация на клиенте, маска телефона, состояние успеха (демо, без бэкенда).
- **Тёмная и светлая темы** — переключатель с сохранением в `localStorage` и учётом `prefers-color-scheme`.
- **Доступность** — семантическая разметка, skip-link, видимый фокус, `prefers-reduced-motion`, контрастные состояния.
- **Адаптив** — от 360 px до широких мониторов.

## Локальный просмотр

Вариант 1 — просто открыть `index.html` в браузере (всё работает по `file://`).

Вариант 2 — локальный сервер (рекомендуется, ближе к реальным условиям):

```bash
# из папки SimpleWebPage
python -m http.server 8000
```

Затем открыть <http://localhost:8000>.

Если установлен Node.js:

```bash
npx serve .
```

## Публикация на GitHub Pages

Проект уже загружен в репозиторий
`https://github.com/LeoVorona/SourceCraftTest` (ветка `main`).

1. Откройте **Settings → Pages**.
2. В блоке **Build and deployment** выберите **Source: Deploy from a branch**.
3. Укажите **Branch: `main`**, папку **`/ (root)`** и нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://leovorona.github.io/SourceCraftTest/`.

Дальше сайт обновляется обычным `git push` в `main` — Pages пересобирает страницу автоматически.

### Если нужен деплой через GitHub Actions

Создайте `.github/workflows/pages.yml` (workflow на `actions/configure-pages`,
`actions/upload-pages-artifact` с `path: .` и `actions/deploy-pages`) и в
**Settings → Pages → Source** выберите **GitHub Actions**. Для статического
сайта это не обязательно — ветка `main` справляется без CI.

## Технические замечания

- **Форма демонстрационная.** Данные никуда не отправляются: после успешной валидации показывается сообщение и форма очищается. Для реальной работы подключите endpoint (fetch/XMLHttpRequest) или сервис вроде Formspree.
- **Изображения — SVG**, поэтому они не требуют отдельной оптимизации и корректно масштабируются. При замене на фотографии используйте формат WebP/AVIF и атрибуты `width`/`height` + `loading="lazy"`.
- **Темы** хранятся в `localStorage` под ключом `swp-theme`; при первом визите берётся системная настройка.
- **Анимации** отключаются при `prefers-reduced-motion: reduce`, canvas-фон при этом не запускается.
- **Сторонние библиотеки не используются** — только нативный CSS (Grid, Flexbox, `clamp()`, CSS-переменные) и ванильный JS.
